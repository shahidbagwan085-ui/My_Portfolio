## ⚙️ Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/your-username/portfolio.git
```

### 2. Navigate to project folder
```bash
cd portfolio
```

### 3. Run Frontend
Open `index.html` in your browser

### 4. Run Backend Server
```bash
npm install
node server.js
```

Server will run on:
```
http://localhost:5000
```
