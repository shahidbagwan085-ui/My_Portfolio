Rakt Dhara

Making blood-bank coordination more responsive.

Problem

Research focus

Center the workflow on matching needs with donor and inventory availability.

Solution & experience

A blood-bank management workflow that brings donor matching and logistics into one place.

Request → Flask app → donor / inventory records → match

Development

CASE STUDY / 02

CrashSense

Shortening the distance between incident and response.

Problem

Delays in detecting an accident and communicating its location can slow down emergency response.

Research focus

Connect incident detection to timely, location-aware alerts.

Solution & experience

A safety system pairing hardware detection, live location sharing, and an alert-monitoring web experience.

Architecture

Hardware → detection → live location → emergency alert

Development

Hardware and web platform integration.

Outcome

A connected incident-to-alert workflow designed to support faster response.

CASE STUDY / 03

NeuroScanX

Making medical-image insights easier to explore.

Problem

Medical-image insights need clear context to be useful and understandable.

Research focus

Pair image analysis with an accessible way to ask questions about results.

Solution & experience

An X-ray analysis concept with a chatbot designed to explain AI-assisted insights.

Architecture

X-ray → PyTorch model → analysis → guided explanation

Development

Python · PyTorch · Medical AI

Outcome

A conversational path for exploring image-analysis results.

This project is an exploration, not a substitute for professional medical diagnosis.
